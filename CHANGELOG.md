# Changelog

This changelog summarizes public-facing development milestones. LRD is currently in Beta development.

## 0.7.13 Beta

- corrected the sample price for `10cc – Live And Let Live` to 8.00;
- new databases can optionally be created with five sample records.

## 0.7.12 Beta

- prepared GitHub portable-release packaging;
- optional sample data when creating a new database.

## 0.7.11 Beta

- LRD uses an available 64-bit Python runtime for development and builds;
- 32-bit Python remains relevant only to the separate private MDB-to-CSV conversion tool.

## 0.7.10 Beta

- official LRD target changed to Windows x64;
- Nuitka build preparation updated for 64-bit Windows.

## 0.7.9 Beta

- CSV import test run and import now show progress, percentage and record count;
- import mapping displays actual LRD field types.

## 0.7.8 Beta

- corrected first-start behavior on Windows;
- added startup error logging.

## 0.7.7 Beta

- LRD can start without an existing database;
- new empty databases can be created directly from the program.

## 0.7.6 Beta

- comfortable CSV import and export;
- field mapping, import profiles, duplicate handling and test run;
- MDB migration separated from the public LRD application.

## 0.7.5 Beta

- visible Beta version status;
- documentation of Windows SmartScreen behavior for unsigned builds.

## 0.7.4 Beta

- automatic and manual SQLite backups;
- configurable retention period for automatic backups;
- manual backups are never automatically deleted.

## 0.7.3 Beta

- user-defined custom fields.

## 0.7.2 Beta

- record-room image integrated into the interface with enlarged view on click.

## 0.7.1 Beta

- application renamed to **LRD – Local Record Desk**;
- local/offline desktop concept documented.

## Earlier development

Earlier 0.6.x/0.7.0 development versions established the SQLite data model, bilingual interface, configurable table, search/filter system, keyboard shortcuts and Freeware licensing.
